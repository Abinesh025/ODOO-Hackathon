Reimbursement Management System (Odoo Hackathon)
📌 Overview

This project is a Reimbursement Management System developed for an Odoo Hackathon. It allows employees to submit expense claims and enables managers to review, approve, or reject reimbursement requests efficiently.

🎯 Features
Employee reimbursement request submission
Upload expense receipts
Approval / rejection workflow
Status tracking (Pending, Approved, Rejected)
Role-based access (Employee, Manager, Admin)
Simple and structured expense management

⚙️ Tech Stack
Odoo Framework
React
MongoDb
XML (Odoo Views)

JavaScript (if required for UI enhancements)

reimbursement_system/
 ├── models/

🚀 How to Run
Install Odoo (compatible version)
Add the module to Odoo addons directory
Update apps list
Install Reimbursement Management System module
Start server and access via Odoo UI
🔐 Roles
Employee: Create and submit reimbursement requests
Manager: Approve or reject requests
Admin: Manage system configuration
